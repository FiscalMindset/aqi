# API reference

Interactive reference: serve the docs site and open `docs/api.md` — it embeds Swagger UI from `openapi/openapi.yaml`. The machine-readable spec is generated from the FastAPI app:

```bash
make openapi     # regenerates openapi/openapi.yaml
```

## Routes

| Route | Purpose | Notable behaviour |
|---|---|---|
| `GET /health` | Liveness | always fast, no I/O |
| `GET /ready` | Readiness | per-component breakdown; 503 when degraded |
| `GET /v1/estimate?lat&lon` | PM2.5 estimate | 422 outside the NCR polygon; 80% interval; `served_by`; `data_age_seconds` |
| `GET /v1/grid` | H3 grid GeoJSON | ETag + 304; gzip |
| `GET /v1/sources?lat&lon&radius_km&upwind` | Upwind source candidates | exact cone test; ODbL attribution |
| `GET /v1/stations?lat&lon` | Nearest CPCB/OpenAQ stations | reading age per station |
| `POST /v1/explain` | Attribution + advice | stricter throttle; full tool trace |
| `GET /v1/subscriptions?` | — | create is `POST` |
| `POST /v1/subscriptions` | Email alert | idempotent by (email, locality); confirmation flow |
| `DELETE /v1/subscriptions/{id}` | Unsubscribe | immediate; removes the SNS subscription |
| `GET /v1/status` | Feed freshness | per-feed `ok`, age, records |
| `GET /v1/validation` | Model metrics | generated by the evaluation script |

## Errors

Every failure is `application/problem+json` (RFC 9457):

```json
{
  "type": "https://api.dhuan-detective.example/problems/outside-coverage",
  "title": "Point outside coverage",
  "status": 422,
  "detail": "The point (19.076, 72.877) is not inside the Delhi-NCR coverage polygon.",
  "correlation_id": "88ae580459384bca"
}
```

| Type | Status | Meaning |
|---|---|---|
| `validation` | 422 | bad request body/params |
| `outside-coverage` | 422 | point is not in Delhi-NCR |
| `not-configured` | 503 | a feed is missing credentials (never fabricated data) |
| `upstream` | 503 | an upstream feed is unavailable |
| `rate-limited` | 429 | API Gateway throttling |
| `not-found` | 404 | unknown resource |
